# hxyfront-62006 珠宝镶嵌 · 配石台

在珠宝分拣壳内实现的镶嵌配石台（React + Vite + TypeScript），预置三张订单与十二颗宝石，纯前端、本地数据，不接后端或外部依赖。

## 功能

- **宝石台账**：编号、种类、形状、克拉、尺寸、净度、颜色、切工、分拣批次、分拣状态、缺陷备注与当前镶嵌位。
- **订单配石**：三张预置订单（戒指 / 吊坠 / 耳饰），按镶嵌位下拉选石，位置示意图与配石行联动。
- **占位规则**：仅「已分拣 且 缺陷已处理」的宝石可占位；同颗宝石跨订单只能待镶一处。
- **整单校验**：形状、尺寸误差、主配石容量线（0.5ct）任一不符，或有重复/跨单占用，则整单不落，原分配保持不变并给出逐位原因。
- **撤回**：撤回待镶订单后全部宝石恢复可分配，配石方案保留待调整。
- **缺陷**：缺陷重新打开会暂停该宝石的待镶占用并自动留档；缺陷关闭后恢复占用/可分配。
- **筛选与批次**：按形状、尺寸分段（小配石/配石/中石/主石）、分拣批次筛选。
- **留档**：落位、被拒、撤回、分拣、缺陷登记/关闭/暂停等事件按时间留档。
- **本地同步**：全部状态写入 `localStorage`，刷新保留；可一键恢复预置数据。

## 本地运行

```bash
npm install
npm run dev
```
